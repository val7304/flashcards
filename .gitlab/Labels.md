## Labels are used to:

* Filter Issues / Merge Requests
* Manage sprint
* Track feature status
* Automate certain actions

prefixed by **MR_** in auto-promote script

---

### Types: 

| Label         | Color     |
| ------------- | --------- |
| feature       | blue      |
| bug           | red       |
| documentation | grey      |
| refactoring   | violet    |
| security      | orange    |
| ci            | aqua      |
| performance   | pink      |

### Priorities:

| Label              | Color     |
| ------------------ | --------- |
| priority::low      | green     |
| priority::medium   | yellow    |
| priority::high     | orange    |
| priority::critical | dark red  |
