## Github vs gitlab

| GitHub              | GitLab       |
| ------------------- | ------------ |
| Workflow            | Pipeline     |
| Job                 | Job          |
| Step                | Script       |
| Actions Marketplace | Templates    |
| Environments        | Rules        |
| Secrets             | CI Variables |
